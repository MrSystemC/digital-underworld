# GENESIS ARCHIVE #001 — NFT «Непрерывность человечества»

**Единственное AI-assisted цифровое произведение · версия комплекта 1.0 · 2 ноября 2026**

Произведение задумано как визуальный фронтиспис предлагаемого «Архива непрерывности человечества». Песочные часы удерживают Землю как память наверху и образ восстанавливающейся цивилизации внизу; символы вокруг отсылают к здоровью, знаниям, чистой энергии, экологии, сотрудничеству, справедливости и исследованию космоса.

## Текущий статус

**Подготовлено к проверке. Не развёрнуто, не заминчено, не прошло независимый аудит и не выставлено на продажу.** Реальные IPFS CID, адрес контракта, транзакции, оценка и принятие аукционным домом пока отсутствуют.

В каталоге размещены исходный ERC-721 контракт, скрипты, тесты, черновик метаданных, provenance, документация и статический сайт-превью. Оригинальный PNG 1254 × 1254 и PDF-досье находятся в отдельном архиве проекта. SVG на сайте — только превью, не мастер-файл NFT.

## Техническая модель

- Ethereum ERC-721, token ID 1, максимум один минт в рамках этого контракта.
- OpenZeppelin Contracts 5.4.0, Solidity 0.8.24.
- URI метаданных IPFS фиксируется при развёртывании.
- EIP-2981 сигнализирует роялти 5%; стандарт не гарантирует выплату на каждой площадке.
- Минт доступен только владельцу контракта и выполняется отдельной транзакцией.
- Контракт не обновляемый, публичного метода изменения метаданных нет.

## Проверка локально

Требуется Node.js 20–22:

    npm install
    npm test
    npm run compile

В среде подготовки прошли проверки синтаксиса JavaScript, JSON и совпадения SHA-256 оригинала. Установка npm-зависимостей завершилась по тайм-ауту; компиляция Solidity и EVM-тесты пока не подтверждены. Независимый аудит не проводился.

## Последовательность выпуска

1. Проверить исходники и юридические раскрытия.
2. Установить зависимости и запустить тесты локально.
3. Закрепить мастер-PNG в IPFS и сохранить реальный CID.
4. Локально задать ARTWORK_CID и выполнить npm run metadata:finalize.
5. Отдельно загрузить финальный metadata/1.json в IPFS.
6. Развернуть и протестировать контракт в Sepolia.
7. Получить независимую проверку контракта и юридических условий.
8. Развернуть в Ethereum Mainnet только после явного подтверждения владельца и подписи кошельком.
9. Верифицировать исходный код и заминтить единственный токен на подтверждённый адрес.
10. Подать полный provenance-пакет на подходящую площадку или в аукционный дом.

См. docs/DEPLOYMENT_RUNBOOK_RU.md, docs/PROVENANCE_AND_RIGHTS.md и docs/SECURITY_AND_DUE_DILIGENCE.md.

## Раскрытие для коллекционера

NFT предоставляет владение блокчейн-токеном, но сам по себе не передаёт авторские права, коммерческую лицензию, долю в организации или фонде, инвестиционный доход, права управления или гарантированную будущую полезность. «Архив непрерывности человечества» пока является концепцией, а не действующим фондом или финансируемой программой. Необходимо раскрывать факт создания произведения с применением ИИ.

Оценка не установлена. Запрашиваемая цена не равна независимой оценке. До заявления цены необходимы экспертная оценка и принятие лота аукционным домом.

Не передавайте seed-фразы и приватные ключи в чат или репозиторий. Локальные файлы окружения не должны попадать в Git. Данные в IPFS по умолчанию публичны.
