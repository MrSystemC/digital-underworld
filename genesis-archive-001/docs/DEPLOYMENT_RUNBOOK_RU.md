# Пошаговый выпуск GENESIS ARCHIVE #001

Это последовательность с необратимыми действиями. Не переходите к Mainnet и минту, пока не выполнены все проверки.

## 1. IPFS

1. Скачайте и распакуйте release ZIP. В GitHub размещены исходники; оригинальный PNG находится в ZIP.
2. В каталоге genesis-archive-001 создайте папку artwork и поместите туда оригинал GENESIS_ARCHIVE_001_MASTER.png.
3. Сверьте SHA-256: 087d6986e5e9e972e854ad6f2558ad26e2ad244a98a6e60e25a677fb9286b5bc.
4. Используйте CID изображения, предоставленный владельцем проекта: bafybeib6huv4ptfmmjmgwhmhvmujqflmxm4hzlamujnnii5lkujopa4zia.
5. Проверьте этот CID как минимум через два независимых публичных IPFS gateway. Если изображение не открывается или hash не соответствует оригиналу, повторно загрузите PNG через выбранный pinning-сервис и используйте новый CID.
6. Локально задайте ARTWORK_CID и выполните npm run metadata:finalize. Скрипт сверит SHA-256 оригинала и обновит metadata/1.json.
7. Загрузите финальный metadata/1.json как отдельный файл в IPFS и сохраните его собственный CID.
8. Задайте METADATA_URI=ipfs://<metadata CID>. Проверьте оба URI независимо. IPFS по умолчанию публичен.

## 2. Кошельки и секреты

- Создайте отдельный кошелёк развёртывания и отдельный адрес получателя роялти.
- Для значимых активов предпочтителен аппаратный кошелёк или проверенный multisig.
- Не отправляйте приватный ключ, seed phrase или секреты RPC в ChatGPT, GitHub, электронную почту или аукционный дом.
- MINT_RECIPIENT должен быть проверен вами вручную. Не используйте биржевой депозитный адрес.

## 3. Установка и тестирование

В каталоге genesis-archive-001:

    npm install
    npm test
    npm run compile

До развёртывания убедитесь, что все тесты проходят. В подготовительной среде установка npm-зависимостей завершилась по тайм-ауту, поэтому компиляция Solidity и EVM-тесты пока не подтверждены. Независимый аудит не проводился.

## 4. Sepolia

1. Скопируйте env.template в локальный файл .env, заполните DEPLOYER_KEY, SEPOLIA_RPC_URL, METADATA_URI и ROYALTY_RECEIVER.
2. Выполните npm run deploy:sepolia.
3. Сохраните адрес и хэш транзакции. Проверьте chain ID 11155111, имя, символ, owner, metadataURI и royaltyInfo.
4. После проверки задайте NFT_CONTRACT_ADDRESS и MINT_RECIPIENT.
5. Выполните npm run mint:sepolia.
6. Проверьте minted() == true, ownerOf(1), tokenURI(1), невозможность повторного минта и отображение метаданных.

## 5. Ethereum Mainnet

Mainnet допустим только после успешных тестов, независимого code review, юридической проверки и вашего явного одобрения затрат и адресов.

1. Задайте Mainnet RPC и локальные переменные окружения.
2. Выполните npm run deploy:mainnet.
3. Сохраните адрес контракта и транзакцию, затем верифицируйте исходный код: npm run verify:mainnet.
4. Ещё раз проверьте адрес получателя и royalty receiver.
5. Только после этого выполните npm run mint:mainnet.
6. Сохраните transaction hash, block number, chain ID, адрес контракта, token ID, владельца, metadata CID и artwork hash.
